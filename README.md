# 🚀 Стартап

**Игра решений: вы — основатель стартапа. Свайпайте карточки и держите баланс денег, команды, клиентов и инвесторов.**

### ▶️ [Играть](https://mysik-portfolio.vercel.app/startup-swipe/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- 30 ситуаций с выбором влево или вправо, как в Reigns
- 4 шкалы: если одна обнулится или переполнится — конец
- Подсказки: точки показывают, какие шкалы изменит решение
- 8 разных концовок и рекорд по прожитым месяцам
- Свайпы на телефоне, стрелки и кнопки на ПК

## Стек

JavaScript, Pointer Events, CSS-анимации. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/startup-swipe.git
cd startup-swipe
python3 -m http.server 8000
```
